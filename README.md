# Personal Profile Badge

A clean, responsive personal profile badge that showcases your information, photo, bio, and social media links on a visually appealing card.

## Description

This project creates a simple yet elegant personal profile badge that can be embedded in websites or used as a standalone landing page. The badge displays a person's name, photo, short bio, and social media links in a modern card format with a background image.

## Features

- Clean and minimalist design
- Responsive layout
- Professional styling with subtle shadow effects
- Circular profile image
- Interactive social media links with hover effects
- Custom background image

## File Structure

The project consists of three main files:

- `index.html` - The HTML structure of the profile badge
- `style.css` - CSS styling for the badge and layout
- Image files:
  - `image/20240801_134329~2.jpg` - Profile picture
  - `image/pexels-pixabay-235985.jpg` - Background image

## Usage

1. Replace the personal information in the HTML file with your own:
   - Name (`<h1>Aliu, Qudus Olalekan</h1>`)
   - Profile image (`<img src="image/20240801_134329~2.jpg" alt="ALiu's Picture" />`)
   - Tagline (`<p>A Junior Developer and a Data Analyst</p>`)
   - Bio description
   - Social media links (X, GitHub, Gmail)

2. Replace the images in the `image` folder:
   - Add your profile picture (recommended dimensions: 150x150 pixels)
   - Replace or adjust the background image as desired

## CSS Styling

The CSS includes:
- A full-page background image
- Card styling with white background and shadow effects
- Circular profile image
- Interactive link styling with different states (hover, visited, active)
- Responsive design considerations

## Customization

You can easily customize this badge by:
- Changing the colors, fonts, and dimensions in the CSS file
- Adding additional social media links
- Modifying the shadow effects
- Adjusting the card width and positioning
- Uncommenting and customizing the circular elements (currently commented out in HTML/CSS)

## Browser Compatibility

This profile badge works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
